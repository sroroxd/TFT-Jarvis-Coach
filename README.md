# TFT Jarvis Coach

Deutschsprachiger Android-Coach für TFT. Das Repository enthält die native
Android-App, die lokalen HUD-Erkennungskomponenten und automatische Tests.

## Android-APK herunterladen

Veröffentlichte APKs findest du unter
https://github.com/sroroxd/TFT-Jarvis-Coach/releases

Die neue Release-Pipeline erzeugt **eine einzelne, direkt installierbare APK**
mit dauerhaftem Signaturschlüssel. Bis zur einmaligen Einrichtung dieses
Schlüssels ist nur der vorhandene Debug-Build aus GitHub Actions verfügbar.

**Wichtig für Updates:** Alte Debug-APKs und die neue dauerhaft signierte
Release-APK haben voraussichtlich verschiedene Signaturen. Beim ersten Wechsel
kann deshalb eine Deinstallation nötig sein. Danach sollen weitere Releases
über die bestehende App installiert werden.

Anleitung für Repository-Eigentümer:
[APK-Updates und einmalige Signatur-Einrichtung](docs/APK-UPDATES.md).
